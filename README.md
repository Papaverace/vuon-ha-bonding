# Vươn Hạ – Bonding Mùa 1

Trang web cho buổi Bonding của dự án thiện nguyện **Vươn Hạ**: giới thiệu dự án, hành trình Mùa 1, Core/Ban, nội quy, cách tính điểm, hỏi đáp và 4 trò chơi online (trắc nghiệm, vòng quay thử thách, đoán chữ, Bingo làm quen).

Toàn bộ trang nằm trong một file `index.html`, mở trực tiếp bằng trình duyệt là chạy.

## Đưa lên mạng bằng GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
